## Verdades que a matriz revela

1. **Uniformes (tema 10) segue órfão** — só o Art. 53 de SE (uniforme do serviço).
   Vive em norma própria (RUE). **Pedido ao Wândrio:** conseguir PDFs específicos;
   até lá o capítulo nasce `pendente` (sem invenção).
2. **Cerimonial (tema 11) TEM fonte: RS** — o Cap. VI do RI/2025 do CBMRS (Arts.
   73–81: formaturas, bandeiras, festas BM, parada diária, galeria, recepção/despedida)
   é a fonte primária do tema. (Correção da 1ª versão desta matriz, que dava o tema
   como órfão — descoberto no de-para fino do RS.)
3. **A dupla SE+GO é a alma dos capítulos de serviço** (temas 6–7) — MT/RN não têm nada
   ali. Sem a correção de rumo do Wândrio, esses capítulos nasceriam vazios.

## Avisos técnicos para a transcrição (Sonnet)

1. **RN**: o markdown contém o Diário Oficial INTEIRO (leis de utilidade pública,
   decreto orçamentário…). O Regulamento é SÓ o trecho "ANEXO ÚNICO" (≈ linhas 76–1096,
   Arts. 1º–56). Nada fora disso entra.
2. **Artefatos de extração de PDF** (ex.: "ór gão", "EST ADO" no RN): o transcritor deve
   corrigir o espaçamento interno óbvio; para o verificador não acusar falso erro,
   **ajustar `verificar_verbatim.py`** para comparar também as versões SEM NENHUM espaço
   (as letras continuam verbatim). Pequena mudança, com teste.
3. **PA é minuta** — transcrever normalmente, mas o campo de fonte deixa claro que não é
   norma vigente (o selo `match` não muda; a UI já mostra a fonte).
4. **DF (621 artigos)**: NÃO transcrever integral — entra seletivamente por tema, guiado
   pelos de-paras finos das próximas rodadas do Fable.
